# Assignment02 — Interactive Canvas Music Toy / 交互式画布音乐玩具

## 中文说明

- 本项目提供两个实现：
  - `index.html`（Canvas 版，浏览器运行）
  - `ui.py`（Matplotlib/Pygame 版，Python 运行）
- 你可以从模板区拖拽形状到 `frame` 内，按住形状上下滑动进行缩放，长按约 650ms 删除。右侧工具栏支持播放/暂停与清空。播放时有红色竖线“播放指针”沿 `frame` 水平移动，按每个形状的横向位置触发音色，循环播放。

### 主要特性
- 拖拽放置：从模板区拖拽 `circle/triangle/square` 到 `frame`。
- 手势编辑：形状内部上下滑动缩放；长按删除（移动超过阈值会取消删除）。
- 播放控制：播放/暂停、清空；循环播放（默认周期 `LOOP_MS = 4000ms`）。
- 播放指针：红色半透明竖线在 `frame` 内移动，指示当前播放位置。
- 音色映射：根据形状类型与纵向位置选择音色。
  - circle → `piano_1..7`
  - triangle → `synth_1..7`
  - square → `drum_1..3`

### 运行（Canvas 版）
1. 进入项目目录：`cd d:\program_try\assignment02`
2. 启动本地服务：`python -m http.server 8000`
3. 打开：`http://localhost:8000/index.html`
4. 单文件版（离线可用）：
   - 运行打包：`python bundle.py`
   - 打开：`http://localhost:8000/index.bundle.html` 或直接双击 `index.bundle.html`

### 运行（Python 版）
1. 激活虚拟环境（PowerShell）：` .\.venv\Scripts\Activate.ps1`
2. 安装依赖：`pip install -r requirements.txt`
3. 运行：`python ui.py`
4. 若窗口未显示，可切换后端：
   - 在文件开头添加：`import matplotlib; matplotlib.use('TkAgg')`
   - 或安装 `PyQt5` 并使用 `Qt5Agg`。

### 交互与参数（Canvas 版）
- 缩放灵敏度：`sensitivity = 0.002`（每像素约 0.2%）
- 长按时间：`650ms`
- 移动取消阈值：`6px`
- 循环时长：`LOOP_MS = 4000`（毫秒）
- 资源封装：`EMBED` 映射 + `assetPath(src)`；打包后图片/音频从内联 `data:` URI 加载。

### 项目结构
- `index.html`：Canvas 交互与音频播放、循环与指针绘制
- `index.bundle.html`：打包生成的单文件页面
- `bundle.py`：资源 Base64 内联打包脚本
- `resource/`：UI 与形状图片
- `sounds/`：音频资源（piano/synth/drum/反馈音）
- `ui.py` / `ui copy.py`：Python 交互版本
- `music.py`：与音频相关的辅助逻辑（如有）

### 故障排查
- 模块缺失：`pip install <模块名>`（如 `numpy`、`matplotlib`、`pygame`、`PyQt5`）
- 浏览器无声：确认系统未禁用自动播放，且资源已正确加载（查看控制台/网络面板）。
- 单文件版错误：重新运行 `python bundle.py`，确保 `const EMBED = { ... }` 已正确注入。

## English

- Two implementations are provided:
  - `index.html` (Canvas version for browsers)
  - `ui.py` (Matplotlib/Pygame version for Python)
- Drag shapes from the template area into the `frame`. Inside a shape, vertical drag scales it; long press (~650ms) deletes it. The toolbar offers Play/Pause and Clear. During playback, a red playhead moves across the `frame` and triggers sounds according to shapes’ horizontal positions, looping continuously.

### Features
- Drag & drop: place `circle/triangle/square` into the `frame`.
- Gesture editing: scale by vertical drag, delete by long press (cancelled if moved beyond tolerance).
- Playback controls: Play/Pause, Clear; loop playback (`LOOP_MS = 4000ms`).
- Playhead: a semi-transparent red line indicating current playback position.
- Sound mapping: instrument chosen by shape type and vertical position.
  - circle → `piano_1..7`
  - triangle → `synth_1..7`
  - square → `drum_1..3`

### Run (Canvas)
1. Go to the project directory: `cd d:\program_try\assignment02`
2. Start a local server: `python -m http.server 8000`
3. Open: `http://localhost:8000/index.html`
4. Single-file build (offline-ready):
   - Bundle: `python bundle.py`
   - Open: `http://localhost:8000/index.bundle.html` or double-click `index.bundle.html`

### Run (Python)
1. Activate venv (PowerShell): ` .\.venv\Scripts\Activate.ps1`
2. Install deps: `pip install -r requirements.txt`
3. Run: `python ui.py`
4. If the window doesn’t show, set a GUI backend:
   - Add at top: `import matplotlib; matplotlib.use('TkAgg')`
   - Or install `PyQt5` and use `Qt5Agg`.

### Interactions & Config (Canvas)
- Scale sensitivity: `sensitivity = 0.002` (~0.2% per pixel)
- Long-press duration: `650ms`
- Move tolerance: `6px`
- Loop length: `LOOP_MS = 4000` (ms)
- Asset embedding: `EMBED` map + `assetPath(src)`; images/audio load from inlined `data:` URIs after bundling.

### Project Layout
- `index.html`: Canvas interactions, audio playback, loop and playhead
- `index.bundle.html`: single-file page generated by bundling
- `bundle.py`: Base64 embedding script for resources
- `resource/`: UI and shape images
- `sounds/`: audio assets (piano/synth/drum/feedback)
- `ui.py` / `ui copy.py`: Python implementation
- `music.py`: audio-related helpers (if used)

### Troubleshooting
- Missing modules: `pip install <module>` (e.g., `numpy`, `matplotlib`, `pygame`, `PyQt5`).
- No sound in browser: check auto-play settings and that assets are loaded (DevTools console/network).
- Single-file issues: re-run `python bundle.py` to ensure `const EMBED = { ... }` is correctly injected.
